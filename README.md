# Proyecto-final-desarrollo-de-sistemas---Equipo-2


Creador: Victor (@Victor8aa)

Descripción
Aplicación CRUD desarrollada en Java con JavaFX y MySQL para gestionar empleados e información especifica de cada uno de ellos como lo es el puesto, salario, id, etc.

Tecnologías
- Java
- JavaFX y FXML
- MySQL
- JDBC
- IntelliJ IDEA

Requisitos
- JDK y JavaFX
- MySQL Server
- Driver JDBC de MySQL

Configuración
1. Clonar o descargar el repositorio.
2. Configurar la conexión a la base de datos
3. Ejecutar la clase `Launcher.java`.
